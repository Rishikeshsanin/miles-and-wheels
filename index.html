Before you book

Frequently asked

Is this a live commercial rental service?

Not yet. This release is a production-style product demo. It does not collect payment or reserve real inventory.

Does sharing my location change vehicles or prices?

No. Location is shown only as a convenience label. The same vehicles, prices and sections remain visible.

What is stored when I create an account?

Only the display name you enter, and only in this browser. There is no server-side user account in this release.

Where does my booking history go?

Booking history is saved locally on this device so the History screen works without a database.
